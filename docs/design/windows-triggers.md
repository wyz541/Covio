# Windows Workbench triggers

Windows egui host 使用顶部悬浮 Workbench 作为主入口。

## 启动

- 无参数启动时，应用在后台运行。
- 应用创建隐藏窗口。窗口不显示任务栏按钮。
- `--background` 保持后台启动。
- `--show` 显示窗口。此参数供开发使用。
- `--window-smoke` 显示窗口。此参数供 Windows 冒烟测试使用。
- `--screenshot` 显示隔离窗口。此参数供截图测试使用。

## 触发方式

- 鼠标进入任一显示器顶部中央 10% 宽度区域。
- 触发区以显示器中心为中点。
- 触发区左右边界各距显示器中心 5% 宽度。
- 触发区高度为显示器顶部 2 像素。
- 鼠标在顶部中央触发区停留 180 ms 后，应用显示 Workbench。
- `Ctrl+Alt+T` 在应用失焦时显示或隐藏窗口。
- 托盘图标左键显示或隐藏窗口。
- 托盘图标右键打开菜单。
- 菜单项 `Show screenshots` 打开 Shelf。
- 菜单项 `Settings` 打开 Settings。
- 菜单项 `Quit Covio` 退出应用。
- 窗口有焦点时，`Ctrl+,` 打开 Settings。
- 窗口有焦点时，`Escape` 隐藏窗口。

## 顶部悬浮窗口

- 顶部触发默认启用。
- 开关位于 Settings > Triggers。
- 开关状态保存在 `%LOCALAPPDATA%\Covio\windows-ui.json`。
- 应用使用鼠标所在显示器。
- 应用在显示器顶部水平居中 Workbench。
- Workbench 使用 960 × 880 逻辑尺寸。
- 窗口无标题栏。
- 窗口不可调整大小。
- 窗口置顶。
- 窗口使用 `WS_EX_TOOLWINDOW`。
- 窗口不显示任务栏按钮。
- 窗口保留当前页面。
- 窗口已经显示时，顶部悬停不切换窗口。
- 显示后必须先离开顶部区域，才能再次触发。
- 触发后 700 ms 内禁止再次触发。
- 全局鼠标轮询间隔为 50 ms。
- 实现不安装低级鼠标钩子。

## 圆角与阴影

- 原生窗口启用透明后台缓冲。
- CentralPanel 不绘制矩形背景。
- Workbench 外框使用 22 点圆角。
- Settings 外框使用 22 点圆角。
- Workbench 和 Settings 的外框不绘制阴影。
- 原生窗口使用按 DPI 缩放的圆角区域。
- DWM 非客户区渲染关闭。
- DWM 窗口边框透明。
- 窗口样式更新后，应用重新建立透明合成。
- 卡片和控件的内部阴影保持不变。

## 首帧与显示

后台线程先执行以下步骤：

1. 将窗口显示在屏幕外。
2. 请求 egui 绘制。
3. 等待首帧完成。等待上限为 750 ms。
4. 将窗口移动到当前显示器上方。
5. 从显示器上方滑动到显示器顶部。
6. 请求 egui 显示和聚焦。

此顺序避免黑色首帧。

## 显示与回收动画

- 展开动画使用 250 ms。
- 展开动画从显示器上方移动到显示器顶部。
- 收回动画使用 190 ms。
- 收回动画从显示器顶部移动到显示器上方。
- 减少动态效果时，两个方向都使用 120 ms。
- 每一帧使用缓出曲线。
- 窗口在动画结束后落在准确位置。
- 收回动画完成后，窗口才发送隐藏状态。

## 自动隐藏

- 鼠标离开 Workbench 后，应用等待 500 ms。
- 等待结束后，应用隐藏 Workbench。
- Settings 页面不自动隐藏。
- 隐藏后 core、托盘和全局快捷键继续运行。
- 再次将鼠标移到屏幕顶部，可以显示 Workbench。

## 窗口状态

- 显示窗口时使用 `ShowWindow(SW_SHOW)`。
- 显示窗口时发送 egui `Visible(true)` 和 `Focus`。
- 隐藏窗口时使用 `ShowWindow(SW_HIDE)`。
- 隐藏窗口时发送 egui `Visible(false)`。
- 窗口样式和原生圆角区域在显示后重新应用。
- 快捷键冲突时应用继续运行。Settings 显示冲突原因。
- `--window-smoke` 验证快捷键冲突不阻止应用启动。

## 平台差异

macOS 的 `Option` + 双指下滑入口依赖 macOS 触摸板和系统手势事件。

Windows `winit` 和 egui 不提供等价的全局触摸板手势。

因此 Windows 使用以下主入口：

- 顶部边缘触发。此入口默认启用。
- `Ctrl+Alt+T`。
- 托盘图标。

## 范围

本实现不包含以下能力：

- Windows 睡眠和合盖控制。
- 剪贴板 paste stack 全局快捷键。
- selected-text capture 全局快捷键。
