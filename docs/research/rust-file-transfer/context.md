# 前因与问题边界

> 本文件定义 Covio 文件传输研究的问题、术语、场景和成功标准。

## 1. 问题类别与适用边界

### 1.1 研究问题

Covio 如何用 Rust 实现 macOS、Windows 和 iOS 的文件传输？
Covio 如何用二维码建立发送方与接收方的首轮信任？
Covio 如何保证直连、relay、后台降级和续传行为一致？
Covio 如何定义大文件、目录、冲突和原子落盘语义？

### 1.2 术语

| 术语 | 定义 |
| --- | --- |
| 设备 | 运行 Covio 的 macOS、Windows 或 iOS 主机 |
| 配对 | 两个设备建立并固定彼此身份的过程 |
| 传输任务 | 一次发送方到接收方的文件集合传输 |
| 文件项 | 普通文件、目录或符号链接的清单记录 |
| 清单 | 文件项的排序集合和总摘要 |
| 分块 | 文件内容的一段定长字节范围 |
| 持久检查点 | 已同步到磁盘且已记录的接收进度 |
| 暂存文件 | 最终提交前使用的同卷临时文件 |
| 可见确认 | 接收方用户看到文件摘要后明确接受或拒绝 |
| 后台降级 | 系统暂停进程后停止网络传输并保存恢复状态 |
| 恢复 | 回到前台后重新验证连接并从检查点继续 |

### 1.3 触发条件

1. 用户选择文件或目录。
2. 用户选择已配对设备。
3. 用户扫描二维码建立新配对。
4. 接收方收到传输请求。
5. 网络从直连切换到 relay。
6. 移动应用进入后台或回到前台。
7. 进程崩溃后重新启动。
8. 目标路径存在同名文件。
9. 磁盘空间不足或目标权限变化。
10. 用户暂停、取消或拒绝传输。

### 1.4 问题分类

| 类别 | 表现 | 主要因素 | 推荐路径 |
| --- | --- | --- | --- |
| 局域网传输 | 同一网络内大文件传输 | 发现、直连、流量控制 | iroh 直连加 QUIC |
| 跨网络传输 | NAT 或防火墙阻断直连 | 打洞、relay、身份固定 | iroh relay 回退 |
| 安全配对 | 二维码可能被拍照或替换 | 一次性密钥、公钥固定、用户确认 | 双向确认加设备密钥 |
| 断点续传 | 网络断开或应用被暂停 | 持久检查点、分块校验 | 确认字节加 SQLite 记录 |
| 原子落盘 | 进程崩溃或磁盘写失败 | 同卷临时文件、同步、重命名 | 暂存后原子提交 |
| 目录语义 | 空目录、重名、符号链接 | 清单、路径校验、平台差异 | 一次快照加显式策略 |
| 移动端后台 | iOS 暂停应用进程 | 系统生命周期、连接失效 | 暂停并持久化，前台恢复 |

### 1.5 状态矩阵

| 状态 | 连接 | 接收确认 | 续传 | 最终文件 |
| --- | --- | --- | --- | --- |
| 正常 | 已连接直连或 relay | 已接受 | 可用 | 校验后提交 |
| 网络断开 | 未连接 | 保持已接受状态 | 等待网络 | 不提交 |
| 应用后台 | 可能失效 | 保持已接受状态 | 暂停 | 不提交 |
| 应用恢复 | 重新验证 | 保持已接受状态 | 从检查点继续 | 校验后提交 |
| 接收方拒绝 | 可连接 | 已拒绝 | 不适用 | 不产生 |
| 发送方取消 | 可连接 | 已接受 | 停止 | 保留已有暂存文件 |
| 接收方取消 | 可连接 | 已取消 | 停止 | 按保留策略处理 |
| 空间不足 | 可连接 | 已接受 | 暂停 | 保持暂存文件 |
| 校验失败 | 可连接 | 已接受 | 可重试 | 不提交 |
| 进程崩溃 | 断开 | 已接受 | 重启后恢复 | 无未校验提交 |
| 配对身份变化 | 可连接 | 阻止 | 不适用 | 不产生 |

### 1.6 解决路径

Covio 使用独立 Rust 传输核心。
Rust 核心负责协议、状态、清单、校验、持久化和文件提交。
平台 UI 负责二维码展示、扫描、接收确认和冲突选择。
传输层优先直连。直连失败后使用加密 relay。
mDNS 只提供局域网发现线索。mDNS 不提供信任。
移动端后台只保存状态。后台不承诺持续传输。
前台恢复后重新验证连接和身份。

## 2. 系统模型与场景

### 2.1 参与者

| 角色 | 职责 |
| --- | --- |
| 发送方用户 | 选择内容、展示二维码、确认配对、发起传输 |
| 接收方用户 | 扫描二维码、核对配对码、接受或拒绝传输 |
| Rust 传输核心 | 管理状态、协议、校验、续传和落盘 |
| 平台 UI | 展示状态、接收用户选择、调用系统能力 |
| 操作系统 | 管理权限、后台生命周期、通知和文件系统 |
| relay 服务 | 在无法直连时转发加密流量 |
| 局域网发现 | 提供候选地址提示，不提供身份保证 |

### 2.2 场景一：同一局域网传输

macOS 设备向 Windows 设备发送目录。
两个设备已完成配对。
发送方选择目录并确认接收方。
接收方看到文件数量和总大小。
接收方接受后，Covio 优先建立直连。
网络抖动由 QUIC 处理。应用只处理会话中断。
目录按清单顺序传输。空目录也生成目录项。
完成后接收方看到校验结果和最终路径。

### 2.3 场景二：跨网络 relay 传输

macOS 设备与 iOS 设备不在同一网络。
直连打洞失败。
Covio 切换 iroh relay。
Relay 只能读取连接元数据。Relay 不能读取文件内容。
接收方必须在传输前看到摘要并接受。
网络恢复后可继续传输。

### 2.4 场景三：iOS 进入后台

iOS 在传输中暂停应用。
Rust 核心先记录已同步检查点。
系统暂停后不再假设 socket 可用。
回到前台后先执行双向身份检查和连接探测。
连接有效时从检查点继续。
连接失效时进入等待网络状态并重试。
界面显示“已暂停”或“正在恢复”。界面不显示“失败”。

### 2.5 场景四：冲突文件

接收目录已有同名文件。
接收方在传输前看到冲突列表。
用户选择“保留两者”“替换”或“跳过”。
默认策略为“保留两者”。
新文件名使用规范后缀。
替换操作只在暂存文件校验通过后执行。
替换失败时原文件保持可见。

### 2.6 场景五：符号链接

发送目录包含符号链接。
Rust 核心枚举目录时不跟随链接。
首版检测到符号链接后返回 `symlink_refused`。
用户可改为跳过符号链接后重试。
Covio 不把链接目标内容伪装成普通文件。

## 3. 适用范围

### 3.1 范围内

- macOS、Windows 和 iOS 第一版。
- Android 的协议预留和 FFI 预留。
- 单文件和目录快照。
- 二维码配对。
- 双向设备身份验证。
- 直连和 relay 回退。
- 大文件、空文件、空目录。
- 冲突选择、暂停、取消和续传。
- BLAKE3 分块校验和文件校验。
- SQLite 持久化。
- iOS 前后台降级。
- 发送方离线队列的元数据保存。

### 3.2 范围外

- 实时目录同步。
- 多版本历史。
- 云端永久存储。
- 匿名公网投递。
- 多人共享空间。
- 符号链接首版保留。
- ACL、xattr、完整 POSIX 权限复制。
- Android 首版实现。
- 正式发布渠道。
- 性能基准的真实结果。

## 4. 成功标准

### 4.1 功能

发送方可以使用二维码建立配对。
发送方和接收方可以核对同一配对码。
接收方可以看到文件数量和总大小。
接收方可以接受或拒绝传输。
配对设备可以重新连接。
直连失败可以切换 relay。
传输中断后可以从持久检查点恢复。
文件夹传输保留空目录。
同名文件按用户策略处理。
符号链接不会被跟随或越界写入。
取消后不出现未完成最终文件。

### 4.2 完整性

接收文件字节与发送文件字节一致。
每个分块通过 BLAKE3 校验。
每个文件通过最终 BLAKE3 校验。
校验失败的文件不提交为最终文件。
清单篡改被身份验证或摘要检查拒绝。
路径穿越被拒绝。
临时文件不能被其他本地用户读取。

### 4.3 恢复与资源

网络恢复后可以继续未完成传输。
应用重启后可以读取任务状态。
磁盘空间不足时任务暂停。
磁盘空间恢复后可以继续。
发送缓冲区有固定上限。
接收缓冲区有固定上限。
后台暂停不会标记任务失败。
前台恢复会先验证连接。

### 4.4 安全

二维码泄露不能自动获得长期访问权。
设备公钥变化会阻止自动连接。
Relay 不能读取文件内容和文件清单。
接收方拒绝后不传输文件内容。
不信任 mDNS 记录作为身份。
不跟随符号链接。
不执行接收文件。
不在日志中记录文件内容和配对密钥。

## 5. 假设与限制

### 5.1 假设

- 第一版用户可以接受一次二维码配对。
- 第一版用户可以接受接收方手动确认。
- iroh 可以在 macOS、Windows 和 iOS 编译。
- iOS 允许前台建立 QUIC 连接。
- 首版不要求后台持续接收。
- 用户设备时间误差不会超过配对二维码有效期。

### 5.2 限制

- iOS 可以随时暂停应用。
- 系统通知不保证唤醒传输。
- 公共 relay 可观察连接元数据。
- 文件系统能力因平台而异。
- Windows 符号链接可能需要额外权限。
- 目录越大，清单和冲突处理成本越高。
- BLAKE3 和 SHA-256 的平台性能尚未实测。

### 5.3 未决项

- 是否在发布版强制使用自建 relay。
- iOS 是否需要后台下载代理。
- 是否在首版支持符号链接保留。
- 是否需要 SHA-256 作为对外清单字段。
- 是否使用 BLAKE3 已验证流格式。
- 设备密钥是否使用硬件后备密钥。
- 首版目录项和总字节上限。
- 公共 relay 的隐私声明和保留期限。
